# Canvas Studio

私人无限画布：文字、图片、生图、线稿、深度图和任务列表。代码在公开 GitHub 仓库；线上版本由 ChatGPT Sites 托管，通过 ChatGPT 登录保护。画布记录保存在 D1，画布内容和图片保存在 R2。

## 使用

打开已发布的网站，登录后新建或打开画布。文字和图片可连到生图框；线稿、深度框在浏览器内处理。文字框输入简短想法后可点击“优化提示词”用文本 API 扩写；图片连接到文字框后可点击“反推”，按 5S 视觉结构生成英文提示词。API 设置中的图像和文本密钥只保存在当前浏览器，换设备需重新填写。不要把密钥提交到 Git。

图像 API 可以添加多个配置并排序，第一项是新生图框的默认配置。每个生图框可单独选择图像模型。配置名称、地址、模型和顺序按登录用户同步到云端；密钥仅在本设备浏览器保存。选中有图片的框，上方工具栏提供调色、裁剪、重绘、擦除、扩图、去文字。前两项在浏览器内完成，其余调用所选图像 API 的 `/images/edits`；重绘、擦除和扩图需要服务兼容 PNG 蒙版。结果留在原框，支持撤销到上一张图片。


## 开发

需要 Node.js 22.13 或更新版本。

```sh
npm ci
npm run build
npm run dev -- --port 5174
```

本地预览的 D1 迁移参见 Sites 模板的迁移说明。`.openai/hosting.json` 保存 Sites 项目 ID 和 D1/R2 绑定。线上部署需将代码推送到 Sites 源仓库后保存并发布版本；推送 GitHub 本身不会自动更新网站。

深度模型和 ONNX WebAssembly 各超过托管平台的单文件大小上限。构建时 `scripts/stage-large-assets.mjs` 将它们放到忽略的 `.sites-runtime/runtime-assets/`，从部署包移出。首次发布后，使用受 `CANVAS_RUNTIME_UPLOAD_TOKEN` 保护的 `/api/runtime-assets/model` 和 `/api/runtime-assets/wasm` 上传这两个文件到 R2；之后版本会继续使用同一份 R2 文件。

## 数据与运行限制

- 页面和 API 均要求登录；每个项目、图片和任务按登录用户 ID 隔离。
- 画布和图片自动保存云端。图片在保存前单独上传，避免在画布数据库中放入巨大的 Base64 字符串。
- 生成请求通过已登录页面保持连接，图像 API 最多等待 20 分钟，任务开始、完成或出错会写入云端。若页面在生成期间关闭、刷新或网络断开，第三方图像 API 没有可查询的任务 ID 时，结果可能无法找回；此时任务列表会在 25 分钟后标为中断。生成期间请保持页面打开。
- API 密钥按设备保存在浏览器本地存储，不进入 GitHub 或云端数据库。

# Canvas Studio

私人无限画布：文字、图片、生图、线稿、深度图和任务列表。代码在公开 GitHub 仓库；线上版本由 ChatGPT Sites 托管，通过 ChatGPT 登录保护。画布记录保存在 D1，画布内容和图片保存在 R2。

## v0.2.0 更新内容（2026-11-26）

- 生图框新增“优化提示词”按钮：输入简短描述后，使用单独配置的文本 API 扩写，并将结果写回当前生图框；文字框原有的优化功能继续可用。
- 输出尺寸改为“分辨率”和“画面比例”两项。分辨率可选 1K、2K、4K，默认 2K；三档都提供 1:1、3:2、2:3、4:3、3:4、5:4、4:5、16:9、9:16、21:9、9:21。保留自动与自定义宽高，以及已有画布保存的尺寸。2K 的 21:9 已实际请求并确认返回 2688×1152；其他新组合是否可用仍取决于所配置的图像 API。
- 纵向等比例图片在生图框内按完整高度展示；框体会随图片高度扩展。图片工具栏和任务列表增加可靠的下载处理，下载失败时显示错误提示。
- API 设置改为直接填写 Key，不再显示从环境变量选择 Key 的下拉框。已有使用环境变量的配置仍可继续使用，输入新 Key 可替换。
- 本版本同时更新在线版源码和 `desktop/` 本地版源码；GitHub Release 提供源码，不包含安装包。推送 GitHub 不会自动部署 ChatGPT Sites 在线站点。

## v0.1.0 更新内容

- API 设置中的两个生图 API 和一个文本 API 均支持获取模型列表；填写 Base URL 和 Key 后可获取、展开或收起列表，输入关键字实时筛选并选择模型，也可手动填写。服务需提供兼容 OpenAI 的 `/models` 接口；本地版支持从环境变量读取 Key。
- 项目列表支持点击名称旁的铅笔直接改名，批量选择并删除项目；卡片显示项目 ID、修改时间和 NAS / Cloudflare 存储位置标记，页面布局更紧凑。
- 此 Release 提供源码，尚未提供安装包或自动更新功能。GitHub 的本版本包含上述更新；已发布的在线站点需要单独部署后才会获得最新功能。

## 使用

打开已发布的网站，登录后新建或打开画布。文字和图片可连到生图框；线稿、深度框在浏览器内处理。文字框输入简短想法后可点击“优化提示词”用文本 API 扩写；图片连接到文字框后可点击“反推”，按 5S 视觉结构生成英文提示词。API 设置中的图像和文本密钥只保存在当前浏览器，可以通过设置中的 Markdown 配置导出与导入迁移到另一台设备。不要把密钥提交到 Git。

API 设置横向列出两个生图 API 和一个文本 API。默认名称依次是 `GPT IMAGE 2.6`、`GEMINI Banana pro`、`GEMINI flash 3.8`；点击名称后的笔图标可改名。第二个生图 API 可设为新生图框的默认配置，每个生图框也可单独选择模型。配置名称、地址、模型和生图优先级按登录用户同步到云端；密钥仅在本设备浏览器保存。选中有图片的框，上方工具栏提供调色、裁剪、重绘、擦除、扩图、去文字。前两项在浏览器内完成，其余调用所选图像 API 的 `/images/edits`；重绘、擦除和扩图需要服务兼容 PNG 蒙版。结果留在原框，支持撤销到上一张图片。

API 设置提供「导入配置」与「导出配置 .md」。从本地版导出的 Markdown 文件可在在线版或另一台设备导入，图像与文本 API 和 Key 会一起载入；点击「保存设置」后生效。也兼容旧版 JSON 配置文件。

`desktop/` 是本地版源码。它的两个存储开关位于 API 设置左侧：均关闭使用当前浏览器；开启 NAS 使用本机配置的共享目录；开启 Cloudflare 使用本机配置的在线站点；两者同时开启会同步到两边。启动、数据目录和配置方式参见 [本地版说明](desktop/README.md)。本机的 `.canvas-studio/config.json` 含私密连接信息，未提交到仓库。


## 开发

需要 Node.js 22.13 或更新版本。

```sh
npm ci
npm run build
npm run dev -- --port 5174
```

本地预览的 D1 迁移参见 Sites 模板的迁移说明。`.openai/hosting.json` 保存 Sites 项目 ID 和 D1/R2 绑定。线上部署需将代码推送到 Sites 源仓库后保存并发布版本；推送 GitHub 本身不会自动更新网站。

深度模型和 ONNX WebAssembly 各超过托管平台的单文件大小上限。构建时 `scripts/stage-large-assets.mjs` 将它们放到忽略的 `.sites-runtime/runtime-assets/`，从部署包移出。首次发布后，使用受 `CANVAS_RUNTIME_UPLOAD_TOKEN` 保护的 `/api/runtime-assets/model` 和 `/api/runtime-assets/wasm` 上传这两个文件到 R2；之后版本会继续使用同一份 R2 文件。

## 数据与运行限制

- 页面和 API 均要求登录；每个项目、图片和任务按登录用户 ID 隔离。
- 画布和图片自动保存云端。图片在保存前单独上传，避免在画布数据库中放入巨大的 Base64 字符串。
- 生成请求通过已登录页面保持连接，图像 API 最多等待 20 分钟，任务开始、完成或出错会写入云端。若页面在生成期间关闭、刷新或网络断开，第三方图像 API 没有可查询的任务 ID 时，结果可能无法找回；此时任务列表会在 25 分钟后标为中断。生成期间请保持页面打开。
- API 密钥按设备保存在浏览器本地存储，不进入 GitHub 或云端数据库。

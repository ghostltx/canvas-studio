# Canvas Studio · 本地无限画布

在浏览器中使用的文字与图片节点画布。文字和参考图连接到生图节点后，可通过兼容 OpenAI Images API 的服务生成图片。

## 启动

需要 Node.js 20.19+。在本目录运行：

```powershell
npm install
npm start
```

然后打开 http://127.0.0.1:5173 。首先进入「我的项目」页；点击左上角的「+」新建空白画布，或点击已有项目继续编辑。停止服务时按 Ctrl+C。

原先唯一的画布会自动成为一个项目，节点、连线、名称和已生成图片会保留。项目卡片按最近修改时间排列，显示画布名称、节点数量和图片预览。编辑器左上角的「项目」按钮返回列表。项目地址带有 `?project=...`，刷新后仍停留在当前画布。

项目页的「导出工作区备份」会下载一份 JSON 文件，供你自行保管本地项目和任务结果；在线版不提供从该文件导入的入口。

## 使用

1. 在右上角「API 设置」添加一个或多个图像 API，填写自定义名称、Base URL、API Key 和模型名称；文本 API 单独配置。拖动图像 API 排序，第一项是新生图框的默认模型，已有生图框保留自己选择的配置。
   「API 设置」右侧的「配色方案」可切换清爽紫、奶油暖沙、雾蓝海岸和石墨夜色。主题会保存在当前浏览器，重新打开后继续使用；API 设置只有点击「保存设置」才会生效。
   本地版的图像和文本 Key 可以从下拉列表选择本机环境变量。变量由本地服务读取，新增变量后需要重启本地服务。API 设置中的「导出配置 .md」会下载可在另一台设备或在线版「导入配置」使用的 Markdown 文件；如果选择了环境变量，导出时会把实际 Key 写入文件。导入后点击「保存设置」生效；也兼容旧版 JSON 配置文件。
2. 从底部工具栏添加文字节点、导入图片、添加生图节点。
3. 从节点右侧圆点拖线，在空白处松开选择下一步：文字框可接文字框或生图框；有图片的框可接文字框、生图框、线稿框或深度框。也可以直接连到已有节点左侧。
4. 在生图框自己的「画面描述」文本区写生成或修改要求，也可以连接独立文字框；两处文字会一起发送。点击「开始生成」，结果直接显示在该框内，框底部的下载按钮可另存图片。
   光标位于生图框内时，也可以按 Ctrl+Enter 直接执行该框的生成。
5. 从图片框（或已有结果的生图框）连线到文字框，点击文字框中的「反推」，文本 API 会分析图片并把提示词写回文字框。
6. 从有图片的框拉线创建「线稿框」或「深度框」，点击框内按钮处理。线稿由浏览器本地图像算法生成；深度图由本地 Depth Anything V2 Small 模型推理。结果保存在对应框内，可下载或继续连线。
7. 选中有图片的框，上方工具栏提供调色、裁剪、重绘、擦除、扩图、去文字。调色和裁剪在浏览器内完成；其余四项调用选定的图像 API。完成后替换当前框的图片，工具栏的撤销按钮可切回上一张图片。重绘和擦除需要在图上涂抹区域；第三方 API 需要兼容带 PNG 蒙版的 `/images/edits`。

多个生图框、线稿框和深度框可以同时运行，各框独立显示处理状态。线稿框和深度框各只接受一张输入图；连接另一张时会替换原来的输入连线。
同一个生图框最多连接一张线稿或深度图。连接新的线稿或深度图时，会替换原来的控制图连线。

双击画布空白处可在鼠标位置弹出文字框、图片框、生图框菜单。单击节点后拖动边角手柄可放大或缩小，尺寸会随画布自动保存。
点击顶部画布名称旁的小笔图标可以修改名称；按 Enter 或点击别处保存，按 Esc 取消。名称随画布内容一起自动保存在当前浏览器。
从节点拉线到空白处松开后，选择的下一节点会创建在松开鼠标的位置。
按住每个节点顶部的标题区域可拖动整个节点；标题文字不会进入选中编辑状态。
选中节点或连线后可按 Delete / Backspace 删除。
API 拒绝提示词或其他请求失败时，错误信息会显示在对应框的下方。

有参考图时调用 `/images/edits`，仅文字时调用 `/images/generations`。服务需要兼容 OpenAI Images 的请求和响应格式，包括 `b64_json` 或图片 URL 结果。部分服务只实现了其中一种接口；这种情况下，另一种模式会显示服务返回的错误。

反推调用独立配置的 `/chat/completions`，文本模型必须支持视觉输入。图像与文本可以使用不同服务、密钥和模型。

生图尺寸支持 `gpt-image-2.6` 的 1K、2K、4K 常用比例以及自定义宽高：两边须为 16 的倍数，比例在 1:3 至 3:1 之间，单边不超过 3840 像素，像素总量不超过 8,294,400。4K 预设包括 2880×2880、3840×2160 与 2160×3840 等。

编辑器右上角、API 设置左侧有「NAS」和「Cloudflare」两个滑动开关。两者关闭时，画布和图片存于当前浏览器 IndexedDB；只开 NAS 时存于 NAS；只开 Cloudflare 时存于在线版的 Cloudflare D1 与 R2；同时打开时两边同步。切换时会迁移现有画布、图片和任务记录；迁移失败会提示错误，原模式保持不变。两个存储端的画布以最近修改时间为准。API 设置、配色方案和开关状态仍保存在当前浏览器的 localStorage。项目页「导出工作区备份」包含画布、图片和任务结果，适合另存备份。

NAS 默认目录为当前用户主目录下的 `.canvas-studio/data`。若要使用指定 NAS，在 `C:\Users\<用户名>\.canvas-studio\config.json` 中设置 `dataDir`，例如 `{"dataDir":"\\\\192.168.100.61\\docker\\canvas-studio\\data"}`。本机已配置为该目录；另一台电脑也需要有该共享目录的访问权限。Cloudflare 模式通过本地服务连接私人在线站点，需要在同一配置文件的 `cloud` 对象中设置 `baseUrl`、`bypassToken` 和 `syncToken`；配置文件不在 Git 仓库。另一台电脑需要复制自己的配置，NAS 模式在外网使用时还需先接入能访问 NAS 的网络。

生图和 AI 图片编辑任务提交后由本地服务继续执行。右侧「生成任务」列表只显示当前画布的任务，并标注生成中、已完成或错误；刷新页面后会重新读取任务状态，并把已完成的结果放回原来的框。升级前的任务归属原有画布。任务首先保存在当前 Windows 用户主目录的 `.canvas-studio/data/tasks`，例如 `C:\Users\<用户名>\.canvas-studio\data\tasks`，随后同步到已开启的 NAS 或 Cloudflare。启动时会把项目旧目录 `data/tasks` 中已有记录与图片复制到新位置。本地服务运行期间，刷新浏览器不会中断已提交的任务。如果本地服务在生成中途重启，通用的同步图像 API 无法找回那次响应，任务会标记为错误。

深度模型文件位于 `public/models/depth-anything-v2-small`，使用 Hugging Face 的 [onnx-community/depth-anything-v2-small](https://huggingface.co/onnx-community/depth-anything-v2-small)（Apache-2.0）量化 ONNX 权重。本地推理不会把输入图片发送到图像 API。
